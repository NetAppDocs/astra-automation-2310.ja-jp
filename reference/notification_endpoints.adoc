= Astra API（ACC）通知エンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
各ユーザーの通知先にルーティングされるイベントを表示します。

通知APIは、通知先を持つイベントへのユーザーごとのアクセスを提供します。
