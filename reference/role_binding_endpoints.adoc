= Astra API（ACC）ロールバインディングエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
アカウント内のユーザーまたはグループに権限を付与するロールバインディングを管理します。ロールバインディングとは、ユーザーまたはグループをロールにリンクさせるものです。

ロールバインディングAPIは、ユーザーアカウントのペア、またはグループアカウントのペア間の関係と、それらに付与される権限のセット（ロール）を記述します。
