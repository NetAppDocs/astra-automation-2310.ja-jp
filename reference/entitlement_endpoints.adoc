= Astra API（ACC）エンタイトルメントエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
有効なライセンスとサブスクリプションによって、アカウントで利用できる機能や容量を確認してください。

エンタイトルメントAPIは、アカウントに対して有効なライセンスおよびサブスクリプションによって有効化される機能または容量を表します。
