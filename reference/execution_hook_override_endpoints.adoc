= Astra API（ACC）実行フックオーバーライドエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
特定のアプリケーションのプリロードされたNetApp実行フックを無効にします。これらのエンドポイントを使用する前に、ページに記載されている非推奨情報を確認してください。

実行フックオーバーライドAPIを使用すると、ユーザーは特定のアプリケーションに対してプリロードされている「netapp」実行フックを無効にすることができます。（*以下のAPI非推奨事項に注意*）
