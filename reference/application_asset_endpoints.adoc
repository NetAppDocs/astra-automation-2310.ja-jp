= Astra API（ACC）アプリケーションアセットエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Astra Controlがアプリケーションの管理に使用する状態情報の内部コレクションにアクセスします。

Application Asset APIは、アプリケーションの管理に使用される状態情報の内部コレクションへのアクセスを提供します。
