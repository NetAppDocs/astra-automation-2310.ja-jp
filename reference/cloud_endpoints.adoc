= Astra API（ACC）クラウドエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
クラウドリソースを管理することで、特定のクラウドに接続し、そのクラウド上のクラスターやアプリケーションを管理できるようになります。

クラウドAPIは、クライアントが特定のクラウドに接続してクラスターやアプリケーションを管理できるように、クラウドのリソースへのアクセスを提供します。
