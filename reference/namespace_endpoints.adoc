= Astra API（ACC）ネームスペースエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
クラスターに属するネームスペースを表示します。これらのエンドポイントは読み取り専用です。

名前空間APIは、特定のクラスタに関連付けられた名前空間を記述するために、名前空間リソースへの読み取り専用アクセスを提供します。
