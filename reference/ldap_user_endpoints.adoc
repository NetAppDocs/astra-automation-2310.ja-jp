= Astra API（ACC）LDAPユーザエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
設定済みのLightweight Directory Access Protocol（LDAP）サーバー上のユーザーを表示します。これらのエンドポイントは読み取り専用です。

LDAP User APIは、設定されたLDAPサーバ内のLDAPユーザーへの読み取り専用アクセスを提供します。
