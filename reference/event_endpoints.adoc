= Astra API（ACC）イベントエンドポイント

:imagesdir: ../media/


[role="lead"]
システムアクティビティを追跡するには、Astra Controlで発生するイベントを確認します。

イベントAPIは、システム内で発生するイベントへのアクセスを提供します。
