= Astra API（ACC）メトリクスエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Astra Controlアカウントのメトリクスを取得して、そのアクティビティとリソース使用量を監視します。

メトリクスAPIは、特定のアカウントに関連付けられたメトリクスを表します。
