= Astra API（ACC）エンドポイントの設定
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Astra Controlアカウントの機能を構成するキー/値のペアである、アカウント設定を管理します。

アカウント設定は、Astraアカウントの既知の機能にとって重要なキー/値ペアの集合です。設定APIは、アカウント設定に関する重要な情報へのアクセスを提供します。
