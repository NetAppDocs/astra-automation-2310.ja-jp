= Astra API（ACC）サブスクリプションエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
お客様のAstra Controlアカウントの有効なサブスクリプションを表示します。

Subscription APIは、アクティブなサブスクリプションを表すために、サブスクリプションリソースへのアクセスを提供します。
