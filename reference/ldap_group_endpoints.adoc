= Astra API（ACC）LDAPグループエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
設定済みのLightweight Directory Access Protocol（LDAP）サーバー上のグループを表示します。これらのエンドポイントは読み取り専用です。

LDAP グループ API は、設定された LDAP サーバ内の LDAP グループへの読み取り専用アクセスを提供します。
