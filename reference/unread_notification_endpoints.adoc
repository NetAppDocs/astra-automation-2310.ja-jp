= Astra API（ACC）未読通知エンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
ユーザーがまだ読んでいない通知を見つけて、既読としてマークします。

未読通知APIは、特定のユーザーによって読まれていない通知に関する情報を提供し、それらを既読としてマークできるようにします。
