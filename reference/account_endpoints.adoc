= Astra API（ACC）アカウントエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
マルチテナントのAstra Control環境でテナントを隔離するアカウントを管理します。

アカウント API は、マルチテナントシステムにおける分離されたテナントを表します。
