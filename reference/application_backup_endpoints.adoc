= Astra API（ACC）アプリケーションバックアップエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
管理対象アプリケーションのバックアップを作成および表示して、そのデータを保護します。

アプリケーションバックアップAPIを使用すると、ユーザーは管理対象アプリケーションのバックアップを作成および表示できます。
