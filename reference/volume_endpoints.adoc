= Astra API（ACC）ボリュームエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
アプリケーションに関連付けられているKubernetesボリュームを表示して、アプリケーションがどのようにストレージを使用しているかを確認してください。

Volume APIは、アプリケーションに関連付けられたKubernetesボリュームに関する情報を提供します。
