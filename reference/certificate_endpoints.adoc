= Astra API（ACC）証明書エンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Astra Controlが発信接続を確立するために使用する、管理者が信頼する証明書を管理します。

証明書アプリAPIは、送信接続の確立に使用される管理者信頼証明書を表します。
