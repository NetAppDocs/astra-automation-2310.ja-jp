= Astra API（ACC）Kubernetes APIリソースエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
クラスター上の Kubernetes API リソースを参照して、Astra Control がサポートしているものを確認します。これらのエンドポイントは読み取り専用です。

Kubernetes API リソース API は、Kubernetes API リソースへの読み取り専用アクセスを提供し、特定のクラスタで Astra によってサポートされているリソースをフィルタリングします。
