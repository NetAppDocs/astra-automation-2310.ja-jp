= Astra API（ACC）アプリのエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Astra Controlが管理していないアプリケーションを含め、クラスタ上のKubernetesアプリケーションを操作します。

App API は、 Astra で管理されていないアプリケーションを含む Kubernetes アプリケーションを表します。
