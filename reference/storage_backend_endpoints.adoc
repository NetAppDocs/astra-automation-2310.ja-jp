= Astra API（ACC）ストレージバックエンドエンドポイント
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
管理対象のクラスターやアプリケーションが利用できるストレージサービスを提供するプロバイダーであるストレージバックエンドを管理します。

ストレージバックエンドAPIは、管理対象クラスタおよびアプリケーションで使用できる、ストレージサービスプロバイダ（ストレージバックエンド）の表現へのアクセスを提供します。
